# 潮汐釣魚村

和朋友一起在 3D 小島上釣魚、聊天、收集魚種的網頁遊戲。手機、電腦都能玩，不用安裝。

## 怎麼玩

- **移動**：電腦用 WASD／方向鍵；手機用左下搖桿
- **釣魚**：走進發光圈，按住蓄力、放開拋竿；浮標猛沉時馬上提竿；拉線時按住收線、放開卸力，讓拉力停在綠色區
- **一起玩**：右上角「玩家」→「開新房間」，把 5 個字母的房間代碼或分享連結傳給朋友。開房的人要一直開著畫面，關掉大家就會斷線
- **裝到手機**：用瀏覽器選單「加到主畫面」，之後從圖示打開會全螢幕、橫向

島約 100 × 95 公尺，有村莊中心、鏡湖與河流、瀑布與山丘、北海灘、東北港口和南邊森林。6 個釣點：月灣河岸（木橋）、鏡湖、瀑布潭、晴潮海邊、港口外海（大型魚）、螢光溪間（森林裡的秘密水潭），加上私人小島的碼頭，共 61 種魚（含墨魚、章魚、魷魚、水母、海馬、海龜、螃蟹、龍蝦）（港口外海有虎鯨、白鯨、抹香鯨、翻車魚、鯨鯊、黑鮪魚等大型海洋生物；小丑魚和彩虹鸚哥魚只有小島釣得到）。按「跳」或空白鍵可以跳躍。

**賺金幣**：到「海邊商店」把魚缸裡的魚賣掉（越重越值錢），到「釣具店」買碳纖維釣竿（400）、深海巨物竿（2,500）和魚餌。好竿子拉線時比較不容易斷，魚餌能提高稀有魚和傳說魚的機率。金幣目前存在自己的瀏覽器裡。

**雲端存檔**：紀錄存在 Supabase（`supabase/schema.sql`）。打開網站會自動用訪客身分登入；到「造型」分頁綁定 Email（點信裡的確認連結），換手機或換瀏覽器時用登入連結就能接回同一份紀錄。釣魚、賣魚、買東西都由伺服器檢查（魚種、重量、價格、金幣），排行榜是全服的。連不上雲端時，遊戲會用這台裝置的紀錄繼續玩。

**公共大廳**：連上雲端後，打開遊戲就會自動進入公共大廳（Supabase Realtime），看到其他正在玩的人、一起聊天。每個大廳最多 16 人，滿了會分到下一個（共 5 個）。想只跟朋友玩，一樣可以在「玩家」分頁開私人房間。在「玩家」分頁或排行榜點別人，可以參觀他的水族館。聊天會自動把髒話變成＊＊（「造型」分頁可以關掉），每人 6 秒內最多 4 則；遇到不禮貌的人可以在「玩家」分頁封鎖（只對自己有效，存在這台裝置）。

**做料理**：廣場旁邊的「潮汐食堂」可以用魚缸裡的魚做鯖魚握壽司、鯛魚握壽司、鹽烤香魚、酥炸河鱸、綜合壽司拼盤，還有章魚燒、烤魷魚串、墨魚麵、三杯小卷、鮪魚大腹握壽司、鰻魚飯、河豚火鍋、紅燒吳郭魚。切魚小遊戲切 3 刀，抓準時機星星越多（最多 ★★★ ×1.6），料理賣給食堂比直接賣魚更值錢。資料庫要多執行一次 `supabase/002_cooking.sql`。

**私人小島**：選單的「🏝️ 小島」可以去自己的島（半徑 24 公尺）。在「買東西擺島上」挑房子或家具（共 22 種），走路調整位置、轉方向後放下；建造模式下走到東西旁邊可以移動或拆掉（退一半）。走到房子門口可以「進屋」，屋裡有床、壁爐、書櫃和展示自己魚的小魚缸。海上看得到按讚最多的別人的島，可以去參觀、幫他按讚。伺服器檢查價格和位置。

**日夜**：遊戲裡的一天是現實 36 分鐘，所有玩家看到的時間都一樣（左上角有時鐘）。有些魚白天、清晨黃昏或晚上比較多，圖鑑上會標示；晚上路燈、窗戶和燈塔會亮。網址加 `#hour=21` 可以固定時間。

- **地圖與傳送**：走過的地點會解鎖，從「地圖」可以直接傳送
- **小船**：港口和鏡湖可以上船，划到水上任何地方釣魚
- **水族館**：廣場北邊的大水族館最多展示 100 條魚，可以在「魚缸」自己挑要放哪些，也能放生
- **拍照模式**：右上角相機按鈕，自由轉動視角、拍照存檔或分享

## 放上 GitHub Pages

1. 把這些檔案放到儲存庫的根目錄（或 `docs/` 資料夾）
2. 儲存庫 **Settings → Pages**
3. **Source** 選 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/ (root)`（或 `/docs`），按 **Save**
4. 約 1 分鐘後網址會出現在同一頁，格式是 `https://帳號.github.io/儲存庫名稱/`

之後更新 `index.html` 再推上去，網站會自動跟著更新。

## 畫質與效能

- 「造型」分頁可以選畫質：自動／低／中／高。自動模式會依手機效能決定，連續卡頓時自動降一級。
- 網址後面加 `#debug` 會顯示效能面板（FPS、繪製次數、三角形數、畫質）。
- 「造型」分頁可以切換「新版／經典」畫面；網址加 `#classic` 也能暫時看經典畫面。
- 網址後面加 `#nomerge` 會關閉靜態物件合併，用來比對畫面是否一致。

## 注意

- **紀錄存在各自的瀏覽器裡**：魚缸、圖鑑存在玩家自己的瀏覽器。LINE、Messenger、Safari 是不同的瀏覽器，各自有一份
- **多人連線**：用 PeerJS 的免費公開伺服器配對，配對後玩家之間直接連線。少數公司或學校網路可能會擋，換手機網路通常就能連
- **排行榜**：要跨所有玩家的排行榜需要自己的伺服器（例如 Supabase），這個版本沒有
