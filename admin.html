怎麼成為管理員

  1. 在這個瀏覽器打開遊戲，用 Email 登入（造型 → 雲端存檔 → 用 Email 登入）。訪客帳號不能當管理員。
  2. 回到這一頁重新整理，下面會出現你的帳號編號和一行指令。
  3. 打開 Supabase 後台 → 左邊「SQL Editor」→ 貼上那一行指令 → 按「Run」。
  4. 回到這一頁重新整理就可以用了。要加其他管理員，請他照 1、2 做，再把他頁面上的指令貼到 SQL Editor。

管理員名單只能從 Supabase 後台加，玩家沒辦法自己把自己變成管理員。手機要收到「有新檢舉」的通知：在同一支手機的遊戲裡，造型 → 打開推播。
